# Gist · 英语精读

一个为考研英语阅读准备的精读网站：导入英文文章，划词、划词组、划句子即时翻译，建立自己的语境单词本和句子本，并用红宝书词表标出文章里的考研词。

运行在 Cloudflare Workers + D1 上，免费额度足够个人和几个朋友使用。

## 功能

- **阅读与翻译**：划选单词、词组（2–4 个词）或句子，用 DeepSeek 结合上下文实时翻译；词组自动归入词组本，也可手动改存。
- **单词本 / 词组本 / 句子本**：分开保存单词、词组和句子及其原文语境，可生成近义词、形近词联想，单词可同步到墨墨背单词。
- **考研词标记**：文章中的考研词用虚线标出（已过滤掉过于基础的词），单词本里的词用粗斜体标出。
- **阅读统计**：只统计真正在读的时间（页面在前台且有操作），显示每日时长、连续天数、30 天柱状图、每日收藏数。
- **考研词覆盖率**：遇到过 / 收藏过的考研词占比，按必考词、基础词分开；每篇文章带来的新词；常考但还没遇到的词。
- **每日自动导入**：提供一个只能添加文章的 MCP 入口，可让 ChatGPT 定时任务每天找一篇文章导入（含原标题、来源、发表日期和 5 字以内的中文简称）。
- **多账号**：管理员在 `/admin` 给朋友开账号，每个账号的数据完全隔离。
- **登录**：黑白极简登录页，登录一次一年内免登录；连续输错 10 次会暂停 15 分钟。

## 技术栈

- [vinext](https://github.com/cloudflare/vinext)（Next.js App Router 运行在 Vite / Cloudflare Workers 上）、React 19、Tailwind CSS 4、shadcn/ui
- Cloudflare Workers + D1（SQLite），数据库迁移在 `drizzle/`
- 翻译与词汇联想：DeepSeek API（每个用户填写自己的 API Key，加密保存）

## 目录

| 路径 | 内容 |
|---|---|
| `app/page.tsx` | 主页面：阅读、单词本、句子本、统计 |
| `app/api/` | 文章库、翻译、词汇联想、墨墨同步、阅读统计等接口 |
| `app/mcp/route.ts` | 每日导入文章的 MCP 工具 |
| `components/` | 文章渲染（考研词 / 词组 / 句子标记）、阅读统计、考研词覆盖率 |
| `lib/kaoyan-vocab*.json` | 考研词表（标记用 / 覆盖率用，含真题出现次数） |
| `self-host/` | 自建部署用的 Worker 入口：登录、多账号、管理页、MCP 连接器 |
| `drizzle/` | D1 数据库迁移 |
